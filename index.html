    Show details

    Language, seasons, episodes, show status, posters, and a short synopsis are looked up online when you add a show.

    Better results for Korean and Chinese dramas

    Shows are looked up on TVmaze, and on Wikipedia when TVmaze has no match. Adding a free TMDB key searches TMDB as well, which covers many more Asian dramas.

    1. Create a free account at themoviedb.org.
    2. Open Settings, then API, and request a key for personal use.
    3. Copy the API Key (v3) or the API Read Access Token and paste it above.
